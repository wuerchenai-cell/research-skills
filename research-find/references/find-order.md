# Find: Reading Order

## Purpose

Propose a reading order for a set of candidates.

## Workflow

1. Order from foundational to specific, or from overview to method.
2. Mark what the user can skip initially.
3. Keep the order tied to the user's immediate goal.

## Quality gates

- The order is justified, not alphabetical.
- The first item is the lowest-cost starting point.
- Later items depend on earlier ones being understood.

## Common pitfalls

- Starting with the most advanced paper.
- Forcing a full reading list when one source is enough.
