# Find: Access Level

## Purpose

State honestly what level of a source is reachable.

## Workflow

1. Check whether full text is locally available.
2. If not, check whether abstract/metadata is reachable.
3. Mark login, payment, captcha, or access barriers.
4. Do not claim full-text reading without verified access.

## Quality gates

- Access level is stated for every candidate.
- Barriers are listed without asking the user to solve them silently.

## Common pitfalls

- Claiming a source was read when only the abstract is available.
- Hiding access barriers.
