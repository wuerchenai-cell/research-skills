# Find: Identity Check

## Purpose

Verify a candidate's identity before recommending it.

## Workflow

1. Check title, authors, venue, year, and version.
2. Check DOI format and whether it resolves to the same title.
3. Check for erratum, correction, retraction, or preprint-vs-published status.
4. Mark unresolved identity issues.

## Quality gates

- Identity is confirmed or explicitly marked uncertain.
- DOI is valid in format and, when checked, matches the title.
- Version status (preprint/published) is stated.

## Common pitfalls

- Treating a search snippet as identity proof.
- Recommending a source without knowing its access level.
