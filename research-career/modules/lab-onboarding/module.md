# Module: 实验室新人清单 (Lab Onboarding Checklist)
Status: stable. Provides `skill辅助（用户无需打开，辅助skill使用）/requirements/lab-onboarding.md` for the active unit.
## When to use
带新来的师弟师妹/实习生，需要一份可复用的环境、账号、规范、必读与首周任务清单时。
## Artifact
`skill辅助（用户无需打开，辅助skill使用）/requirements/lab-onboarding.md` — 自由结构模板，含日期/类型/参与人/要点/决策/行动项等区块。
## Rules
- 清单随实验室演进更新；新人完成一项勾一项。
- 必读项链接到 reference-manager 或 资料/。
## Do not
- 不要把新人个人信息写进共享清单。
- 不要把清单放在单元根 .md（违反 R3，应落 requirements/）。
