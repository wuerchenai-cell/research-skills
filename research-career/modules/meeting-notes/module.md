# Module: 组会与汇报记录 (Meeting & Talk Notes)
Status: stable. Provides `skill辅助（用户无需打开，辅助skill使用）/requirements/meeting-notes.md` for the active unit.
## When to use
每周组会、开题/中期/预答辩预演、外邀 seminar、与合作者 sync 之后。把决策、行动项、待跟进沉淀下来。
## Artifact
`skill辅助（用户无需打开，辅助skill使用）/requirements/meeting-notes.md` — 自由结构模板，含日期/类型/参与人/要点/决策/行动项等区块。
## Rules
- 每次会议一条记录；行动项必须带 owner 与 due，否则等于没记。
- 决策类内容同时可在 decision-log 模块沉淀为长期可追溯条目。
## Do not
- 不要把录音/幻灯片正文塞进这里；幻灯片放 资料/，这里只记结论与行动。
- 不要另存为单元根 .md（违反 R3，应落在辅助层 requirements/）。
