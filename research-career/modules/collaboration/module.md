# Module: 跨组协作登记 (Collaboration Registry)
Status: stable. Provides `skill辅助（用户无需打开，辅助skill使用）/requirements/collaboration.md` for the active unit.
## When to use
与校外/跨课题组合作，需要明确角色、分工、共享文献与 IP 归属，避免'谁负责啥'扯皮时。
## Artifact
`skill辅助（用户无需打开，辅助skill使用）/requirements/collaboration.md` — 自由结构模板，含日期/类型/参与人/要点/决策/行动项等区块。
## Rules
- 协作启动前先填 IP 与署名约定，避免后期纠纷。
- 共享文献用 reference-manager，代码仓库在此登记链接。
## Do not
- 不要把合作方隐私信息（未公开）外泄到非受控位置。
- 不要等出问题才补分工——启动即登记。
