# Module: 助教与授课记录 (Teaching Log)
Status: stable. Provides `skill辅助（用户无需打开，辅助skill使用）/requirements/teaching.md` for the active unit.
## When to use
当 TA 或独立授课，需要管大纲、作业、答疑与考点题库时。
## Artifact
`skill辅助（用户无需打开，辅助skill使用）/requirements/teaching.md` — 自由结构模板，含日期/类型/参与人/要点/决策/行动项等区块。
## Rules
- Q&A 题库跨学期复用，逐年沉淀。
- 作业与答案放 资料/，这里只做教学元数据与题库。
## Do not
- 不要把学生隐私成绩外泄到非受控位置。
- 不要把整本讲义放辅助层——讲义在 资料/。
