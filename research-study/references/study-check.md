# Study: Understanding Check

## Purpose

Verify the user can reproduce the key reasoning.

## Workflow

1. Ask the user to explain the concept in their own words.
2. Provide a transfer problem.
3. Ask the user to identify assumptions and boundary conditions.
4. Provide a counterexample or failure case.

## Quality gates

- The user can explain the concept without looking at the material.
- The user can solve a transfer problem.
- The user can identify assumptions.
- The user can explain a failure case.

## Common pitfalls

- Asking recall questions instead of transfer questions.
- Skipping the counterexample.
- Treating familiarity with the vocabulary as understanding.
