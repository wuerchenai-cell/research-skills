# Study: Prerequisite Diagnosis

## Purpose

Identify missing prerequisites and start at the first missing dependency.

## Workflow

1. Identify the target capability: explain, derive, calculate, implement, critique, or apply.
2. Identify prerequisite concepts.
3. Classify each prerequisite as secure, fragile, or missing.
4. Start at the first missing dependency.

## Quality gates

- Each prerequisite is classified.
- The first missing dependency is identified.
- Secure prerequisites are not re-taught.

## Common pitfalls

- Asking dozens of diagnostic questions.
- Re-teaching secure concepts.
- Skipping fragile prerequisites.
- Starting at the most advanced topic instead of the first missing dependency.
